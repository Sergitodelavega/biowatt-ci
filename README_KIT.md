# BIOWATT-CI — Kit Antigravity

Ce dossier contient les fichiers de pilotage spec-first pour développer BIOWATT-CI avec Antigravity.

## Fichiers

- `AGENTS.md` : règles de comportement et de développement de l’agent.
- `TASKS.md` : backlog structuré par phases.
- `PROGRESS.md` : suivi de l’avancement.
- `MASTER_PROMPT_ANTIGRAVITY.md` : premier prompt maître.
- `specs/auth.md` : authentification, comptes et rôles.
- `specs/feedstocks.md` : gisements.
- `specs/biogas-units.md` : unités de biogaz.
- `specs/simulator.md` : simulateur de potentiel.
- `specs/matching.md` : Smart Matching.
- `specs/dashboards.md` : tableaux de bord.
- `specs/exports.md` : exports, audit et gouvernance.

## Utilisation

1. Copier ces fichiers à la racine du dépôt BIOWATT-CI.
2. Placer la spécification principale dans `SPEC.md`.
3. Vérifier les décisions encore ouvertes.
4. Ouvrir le projet avec Antigravity.
5. Donner `MASTER_PROMPT_ANTIGRAVITY.md` comme prompt initial.
6. Faire avancer le projet incrément par incrément.
